# computeRegistry

Personal compute registry and session lease service for coordinating AI agents across local, remote, organizational, and project-scoped compute resources.

## Stack

- Next.js 16 / React 19
- Supabase Postgres + Auth
- Vercel

## Status

Initial scaffold. The Supabase `compute-registry` project already contains the core resource/session schema. Client access remains locked down until authentication policies are wired.
